# Attribution

This is an unofficial adaptation of the Karpathy Guidelines skill from
[multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills/blob/2c606141936f1eeef17fa3043a72095b4765b9c2/skills/karpathy-guidelines/SKILL.md).
That file declares the MIT license in its frontmatter. It attributes its coding
observations to [Andrej Karpathy](https://x.com/karpathy/status/2015883857489522876).

The revision was prepared by ajitta using dia-regula 2.2.0. It consolidates
conditions and actions and adds explanatory reasons while retaining the core
requirements. Packaging changes the skill's identifier to `coding-guidelines`;
the reviewed Markdown body is preserved.

Neither Andrej Karpathy nor the upstream maintainers are claimed to endorse
this plugin. dia-regula is an editing method, not a runtime dependency.

[Research record](https://github.com/ajitta/dialectic-skills/tree/main/docs/research/karpathy-regula-2026-11-08)
documents the review, corrections, limited behavioral runs, and process analysis.
It does not establish a general performance improvement over the original.
